# 公司模式在原先显示 id 和路径的地方显示名称和文件夹

- **Date:** 2026-09-16
- **Type:** feature
- **Scope:** `web`

[English](2026-09-16-company-readable-names.md)

公司模式有三处不再让人读机器写法：在频道输入框里 `@` 选中的 Agent 写入名称而不是 id，工单里的数据路径渲染为文件夹胶囊，
组织状态以文字胶囊的形式放在组织名称旁边。

## 频道输入框里的提及

- 从 `@` 菜单选中后，输入框写入的是显示名称（`@Ada Lovelace`），并按已发送消息里提及标签的样子着色；此前写入的是 id。
  发出的消息仍然携带 id（`@ceo`、`@user:alice`、`@all`），因此服务端、投递与 `mention_not_member` 均未改变。
- 每次选中都作为草稿中的一段区间被记录。在名称内部输入、删掉其中一部分、或替换跨过它的选区，都会让它变回普通文本；
  在其他位置输入或粘贴只会让它随之移动。紧贴在前面单词上的提及，或后面紧跟着会延长 id 的字符（`@Ada.md`）的提及，
  按可见文本发出并失去着色，直到删掉多余字符为止。同名员工不会混淆，手动输入或粘贴的 `@id` 照旧可用。
- 菜单也能匹配以任意文字输入的名称（`@张`）；在 `@` 之后用输入法组字时按 Enter 不再选中候选。

## 工单里的路径

- 工单弹窗中的目标、验收标准、进展、结果与阻塞原因把数据路径画成胶囊：文件夹或文件图标加最后一段名称，悬停显示完整路径，
  点击按原样复制路径，图标随之变成对勾。存储的文本未改变。
- 路径指 `<app_data_dir>/…`，或经过该 Project 的 `organizations/`、`agents/` 目录的绝对路径。正文里的路径只由 ASCII
  文件名字符组成，遇到空格、中日韩文字或标点即结束，句末的句点不计入路径。只含一条路径的行内代码按原样变为胶囊；
  代码块、行内代码里的命令与链接文字保持原样。以 `/` 结尾、或最后一段没有扩展名的读作文件夹；最后一段带扩展名的读作文件。

## 组织状态

- 组织切换器的触发按钮把状态显示为名称右侧的文字胶囊——运行中 / 已暂停 / 配置无效（英文为 Running / Paused /
  Invalid configuration）——取代名称前的圆点。空间不够时先截断名称，状态也并入了触发按钮的无障碍名称。
- 未暂停组织的英文标签在所有出现处由 "Active" 改为 "Running"。
