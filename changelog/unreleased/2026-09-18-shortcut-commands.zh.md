# 新增六条快捷键：搜索、新建对话、侧栏、停靠栏、新建终端

- **Date:** 2026-09-18
- **Type:** feature
- **Scope:** `web`

[English](2026-09-18-shortcut-commands.md)

快捷键注册表新增六条命令，都可在设置的「快捷键」页改绑（`Mod` 在 macOS 为 ⌘，其余平台为 Ctrl）：搜索会话（Mod+K）、新建对话（Mod+Shift+O）、显示或隐藏侧栏（Mod+B）、显示或隐藏右侧停靠栏（Mod+Alt+B）、显示或隐藏底部停靠栏（Mod+J），以及新建终端（所有平台均为 Ctrl+Shift+`，与显示 / 隐藏终端的 Ctrl+` 相邻）。执行同一动作的按钮——对话工具行的停靠栏开关、侧栏的搜索与新建对话按钮、侧栏折叠控件——在悬停提示里写明组合。

## 细节

- 搜索会话打开侧栏的搜索框，已打开时把光标放回其中；侧栏收成图标栏时，第一次按下先展开侧栏。
- 新建对话从任何位置进入草稿页，侧栏展开与否都可用。
- 设置页此前为空的「面板」分组现在放置侧栏与停靠栏的开关。
