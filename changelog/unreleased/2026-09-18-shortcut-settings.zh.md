# 新增「快捷键」设置页，绑定按账号保存

- **Date:** 2026-09-18
- **Type:** feature
- **Scope:** `web`, `server`
- **PR:** [#789](https://github.com/Prism-Shadow/penguin-harness/pull/789)

[English](2026-09-18-shortcut-settings.md)

系统设置对话框的「个人」分组在「外观」之后新增**快捷键**页：按分组列出全部可改绑的命令及其当前组合，按平台写法显示（Mac 上为 `⌘W`，其余平台为 `Ctrl+W`）。点击组合即录制下一次按下的组合：Esc 取消，Backspace 或 Delete 清除绑定，无修饰键的按键除 F 键外不接受。每行可恢复默认，整页可一次清除全部覆盖。绑定按账号存于 `ui_prefs.keybindings`，并即刻同步到该账号已打开的全部标签页。

## 细节

- 一行按当前绑定不会生效时会给出说明：另一条命令使用同一组合（并说明谁生效）、浏览器自身保留的组合（只在桌面应用里生效），或在桌面应用中，壳自身绑定或菜单同样带有的组合。
- `PUT /api/me/prefs` 校验 `keybindings`：版本号 1，按平台分节（`mac`、`windows`、`linux`），每节至多 64 条，命令 id 与组合串按文法与长度上限检查，整体不超过 8 KiB。不合法的文档以 `invalid_keybindings` 拒绝，该请求不落库任何内容。
- 登录后账号的副本覆盖浏览器镜像；应答到达前做出的修改会推送到账号，账号中不存在的镜像会被清除，共用一台浏览器时一个账号的绑定不会带进另一个账号。写入服务端失败时给出提示并保留镜像。
- 设置行的提示新增 attention 色调，冲突提示使用它。
